AI Shader Graph

2026 · Bachelor Thesis · Generative Tooling
UnityC#Generative AIShader GraphTooling

My bachelor thesis: a Unity editor tool that generates working Shader Graphs from plain-language prompts. It pairs a large language model with a retrieval-augmented knowledge base of Unity's shader nodes and a factory-pattern architecture that assembles the graph — which required reverse-engineering Unity's undocumented Shader Graph file format so the tool writes valid graphs the editor accepts.

Generated graphs reached 98% technical validity in testing, and an 18-participant user study surfaced an "expertise inverse": beginners benefited most, experts were quickest to find the edges. Node-addition workflows dropped from ~45–60 minutes to ~5–10.

An interactive museum experience for Meta Quest 3: visitors place puppets into a virtual theater in mixed reality, triggering AI-generated plays around the life and works of Goethe — 80+ OptiTrack motion-captured animations, ragdoll physics, room mapping, AI storytelling and text-to-speech.
